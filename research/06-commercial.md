# Этап 6. Коммерческая проверка

Базовый факт: RPM Shorts $0.03–0.08 → реклама YouTube = кэшфлоу-добавка, не бизнес. Оценка каналов дохода по кандидатам:

## A. Анимированный explainer

| Канал дохода | Оценка | Обоснование |
|---|---|---|
| YPP (Shorts) | Слабый | Ставки выше средних (education), но всё равно центы |
| Длинные видео | **Сильный** | Прямой прецедент: Zack D. Films — оценки $789K–1.5M+/мес; explainer конвертируется в 3–8-мин компиляции и глубокие разборы с RPM в 10–20x |
| Спонсоры | Сильный | Education-аудитория, бренд-safe формат |
| Партнерские ссылки | Средний | Тематические подводки (наука, гаджеты, здоровье) |
| Товары | Слабый-средний | Нет персонажа-носителя |
| Масштабирование | **Сильное** | Языковые дубли конвейером (та же анимация + переозвучка) — мультипликация каналов по рынкам |

## B. Персонажная анимация (свой IP)

| Канал дохода | Оценка | Обоснование |
|---|---|---|
| YPP (Shorts) | Слабый (объемный) | Giggy: оценка $373K–1M/мес на 2.68 млрд просмотров — работает только на гигантских объемах |
| Длинные видео | Средний | Компиляции эпизодов (модель Larva/Monica Toy) |
| Спонсоры | Средний | Продукт-плейсмент в гэгах |
| Товары/лицензии | **Сильный (уникальный)** | Персонаж = лицензируемый актив: мерч, стикеры, игры. Monica Toy — часть франшизы Mauricio de Sousa |
| Масштабирование | **Сильнейшее** | Без слов = ноль затрат на локализацию, одна версия на весь мир |

## C. Психология/факты — исключен на Этапе 4, коммерческая проверка не проводилась.

## Вывод

Оба финалиста коммерчески состоятельны при обязательном условии: **Shorts = машина дистрибуции, деньги = длинные видео + спонсоры (A) или IP-лицензирование (B).**
