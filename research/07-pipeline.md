# Конвейер покадрового анализа (запуск после одобрения vidIQ)

Что не было выполнено в этой сессии и как это выполнить за одну следующую (при одобренном коннекторе vidIQ). Бюджет: ~1 500–2 000 кредитов vidIQ.

## Шаг 1. Датасет 100+ роликов (≈150 кредитов)

Для каждой категории (Animation, Explainer, Satisfying, Humor, Stories, Education, Luxury, Products, Animals, + регионы US/Hindi/Arabic/EU):

```
vidiq_outliers(contentType: "short", publishedWithin: "threeMonths",
               minViews: 1_000_000, sort: "score", limit: 20, keyword: <категория>)
vidiq_trending_videos(videoFormat: "short", sortBy: "vph", limit: 20)
```

Фиксировать: videoId, канал, просмотры, VPH, breakout score, дату, длительность, подписчиков канала.

## Шаг 2. Покадровый разбор (25 кредитов/ролик; 50 роликов ≈ 1 250)

По стратифицированной выборке 50 роликов (5 на категорию):

```
vidiq_video_watch(video: <id>, prompt: "Опиши: (1) что в кадре в первые 0.5 сек и есть ли движение/лицо/текст/объект; (2) что меняется к 2-й секунде, есть ли конфликт или вопрос; (3) тайм-коды каждой смены сцены; (4) число сцен и средняя длина; (5) есть ли нарастание напряжения; (6) неожиданный ли финал; (7) замыкается ли конец на начало (луп)")
```

## Шаг 3. Комментарии и повторяемость (5 кредитов/вызов)

```
vidiq_video_comments(videoId, order: "relevance")   # почему пишут комментарии
vidiq_channel_videos(channelId, videoFormat: "short")  # 3+ повторяющихся вирусных = системность
```

## Шаг 4. Агрегация

Скрипт сводит проценты по чек-листу Этапа 1 (движение в 0.5с / текст / смена кадра ≤2с / луп / твист) — получаем СВОИ цифры вида «83% начинаются с движения» вместо цитирования чужих исследований.

## Шаг 5. Валидация ниш-финалистов

По 5 каналов на нишу: `vidiq_channel_stats` (рост 30 дней), `vidiq_channel_videos` (последние 10 роликов), подтверждение 3+ вирусных повторов. Заполняет пробел Этапа 3 (кандидат A: копииZack D.; кандидат C: лидеры психологии).
