## Механика удержания

- **Сквозная загадка (Зейгарник):** золотой предмет зарыт под 5 слоями; каждый блок снимает один слой; предмет опознаётся только в финале. Свайп до развязки = дискомфорт незакрытого цикла.
- **Смена класса текстуры каждые 10с (анти-габитуация):** липкая слизь → хрустящая карамель → кинетический песок → желе → тающий лёд → металл/вельвет.
- **Каждый блок обрывается на 80–90% своего цикла** — последние нити слизи, полускрытый предмет — тянет в следующий блок.
- **Развязка:** золотой ключ на вельвете. Серийность: «что спрятано в следующем видео?» — голосование в закрепе.
- Звук: чистый granular ASMR, no music no voices, свой на каждый слой.

## v2 — ИСПРАВЛЕНИЕ КОНСИСТЕНТНОСТИ (12.07.2026)

Фидбек пользователя по v1: «везде всё разное». Причины: кадры дрейфовали (одиночный референс), а клипы, генерируемые только от стартового кадра, заканчивались не там, где начинался следующий блок.

Исправления (новые правила конвейера):
1. **Двойной якорь для кадров:** каждый кадр N генерируется с рефами [кадр №1 (глобальный вид: рука, перчатка, поверхность, свет) + кадр N-1 (состояние слоёв)] + вербатим-блок "SAME SCENE, IDENTICAL in every fixed element".
2. **Клипы со start_image + end_image** (kling3_0 поддерживает): клип обязан закончиться ровно в стартовом кадре следующего блока — стыки бесшовные по построению.
3. **Квадрат 1:1 нативно** (kling3_0 поддерживает 1:1) — формат канала без кропа.
4. Ограничение среды зафиксировано: агент не видит отрендеренные пиксели (сеть закрыта) — верификация консистентности только конструкцией + глазами пользователя.
