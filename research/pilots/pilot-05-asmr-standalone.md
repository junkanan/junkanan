# Пилот #5 — Отдельные реалистичные ASMR-клипы по 15 секунд

Фидбек пользователя по pilot-04 v2 («Золотой ключ», слоёная история): «вообще не реалистично, лучше делай по отдельности все по 15 секунд разные вещи».

Новая логика: НЕ единая история, а НЕЗАВИСИМЫЕ самодостаточные клипы. Каждый клип = одна вещь / одна текстура, максимум реализма. Пользователь отбирает победителей глазами, только потом масштабируем/собираем.

## Параметры производства

- Модель: kling3_0, duration=15 (максимум), aspect 1:1 (формат канала), sound="on" (нативный ASMR-звук).
- Стоимость: 30 кредитов за клип (подтверждено get_cost 12.07.2026).
- Формула реализма в каждом промпте: «Real macro video footage, DSLR macro lens, natural light» + «real human hand(s)» + «real physics» + «static camera, single continuous take» + «no music, no voices» + «motion begins immediately from the first frame» + «photorealistic, indistinguishable from real ASMR footage».
- Запрещено: фэнтези-объекты, слоёные конструкции, летящие жидкости без контакта, склейки.
- Известный перехват: промпт с мёдом словил preset_recommendation «IN THE DARK» → retry c declined_preset_id 24bae836-2c4a-48e0-89b6-49fcc0b21612.
