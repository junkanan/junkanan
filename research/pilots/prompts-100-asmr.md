# 100 промтов ASMR мирового уровня — для безлимитной веб-генерации (Seedance/Kling)

## Как пользоваться

Каждый промт = ШАПКА + ядро сцены + ХВОСТ. Скопируй шапку, вставь ядро из списка, добавь хвост.

**ШАПКА (одинаковая для всех):**

```
Ultra-photorealistic cinematic macro footage, physically-based rendering, ray-traced light, shallow depth of field.
```

**ХВОСТ (одинаковый для всех):**

```
The object is revealed gradually, never all at once; a new satisfying visual event every second; the finale is the most satisfying moment. Rich spatial ASMR audio perfectly synced to every action — no music, no voices. Single continuous take, very slow cinematic push-in, motion begins immediately from the first frame.
```

**Настройки:** duration 15, aspect 9:16, mode std, 1080p или 4k, audio ON, bitrate high.

**Правила отбора после генерации:** физика жидкостей и пальцы — главные места, где AI палится; если сцена вышла неубедительной, не публикуй — замени соседней из той же категории. Публикуй сериями по категориям и сравнивай Viewed-vs-Swiped: категория-лидер получает следующие 20 сюжетов.
